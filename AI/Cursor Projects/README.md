# Streamlit Calculator App

A simple calculator application built with Python and Streamlit.

## Features

- Basic mathematical operations: addition, subtraction, multiplication, division, and power
- User-friendly interface
- Error handling for division by zero

## Installation

1. Install the required dependencies:

```
pip install -r requirements.txt
```

## Running the App

To run the calculator app, use the following command:

```
streamlit run calculator_app.py
```

This will start the Streamlit server and open the calculator app in your default web browser.

## Usage

1. Enter two numbers
2. Select the operation you want to perform
3. Click the "Calculate" button to see the result
